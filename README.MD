## Информация о программе
Данная программа позволяет скрыть полную информацию о банковских продуктах, такие как номера банковских карт,

## Инструкция по использованию
### Модуль .src/widget.py предоставляет функции для:
1. Маскировки номеров банковских карт и счетов;
    - Функция mask_account_card принимает строку с типом и номером (карта или счёт) и возвращает замаскированный вариант. 
#### Пример входящих данных:
```
Visa Platinum 7000792289606361
Счет 73654108430135874305
```

#### Пример результата:
```
Visa Platinum 7000 **** **** 6361
Счет **4305
```
Модуль определяет наименование продукта и вызывает соответствующую функцию для маскировки.

2. Преобразования даты в удобный формат.
    - Функция get_date преобразует дату в формат ДД.ММ.ГГГГ
#### Пример:
```get_date("2024-03-11T02:26:18.671407")```

### Результат:
```11.03.2024```


### Модуль .src/processing.py предоставляет функции для:
1. Фильтрации транзакций по указанному статусу.
   - Функция filter_by_state фильтрует транзакции по указанному статусу. 
По умолчанию возвращает только транзакции со статусом "EXECUTED" (выполненно)
#### Пример использования:
```
data = [
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}
]

print(filter_by_state(data))
```
#### Результат:
```
[{"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"}]
```

2. Сортировки списков транзакций по дате.
   - Функция sort_by_date сортирует список транзакций по дате (по умолчанию - в порядке убывания.)
#### Пример использования:
```
print(sort_by_date(data))
```
#### Результат:
```
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

```
